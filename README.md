# Meu RPG

Protótipo de RPG 2D desenvolvido com Phaser 3.

## Recursos

- Cenário de uma casa.
- Personagem controlável.
- Movimentação pelo teclado.
- Paredes e colisões.
- Gráficos criados diretamente pelo Phaser.
- Sem necessidade de imagens externas.

## Controles

- Setas do teclado: movimentação.
- W, A, S, D: movimentação alternativa.

## Tecnologias

- HTML
- CSS
- JavaScript
- Phaser 3

## Publicação

O projeto pode ser publicado no GitHub Pages.

Acesse Settings > Pages e configure a publicação a partir da branch `main`, usando a pasta `/ (root)`.
